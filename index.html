PROJETO DEVOPS

Desenvolvimento com CI/CD

Um projeto desenvolvido para colocar em prática conceitos de integração contínua, entrega contínua e automação utilizando GitHub.

Conhecer projeto

Sobre o projeto

O DevFlow foi desenvolvido como atividade prática da disciplina de DevOps. O objetivo é utilizar um projeto real para implementar um fluxo completo de CI/CD.

GitHub

Controle de versão e colaboração através de branches e pull requests.

CI

Automação de testes e validações a cada alteração realizada no projeto.

CD

Automatização do processo de publicação da aplicação.

Fluxo CI/CD

01. Código

O desenvolvedor realiza alterações no projeto e envia o código para o repositório.

02. Integração

O GitHub Actions executa automaticamente as verificações e testes do projeto.

03. Deploy

Após as validações, a aplicação pode ser disponibilizada automaticamente.

Objetivos

Automação

Automatizar processos de desenvolvimento, testes e publicação da aplicação.

Qualidade

Identificar problemas antes que novas versões sejam disponibilizadas.

Entrega

Tornar o processo de entrega mais rápido, seguro e confiável.

Benefícios

Mais agilidade

Redução do tempo entre o desenvolvimento e a disponibilização de novas versões.

Mais segurança

Validações automáticas ajudam a identificar problemas antes da publicação.

Melhoria contínua

A automação facilita a evolução constante do projeto.

Etapas do pipeline

01 — Develop

Desenvolvimento das funcionalidades e alterações no código da aplicação.

02 — Test

Execução de validações automáticas para verificar a qualidade do projeto.

03 — Deploy

Publicação da versão validada para disponibilização da aplicação.

Tecnologias
